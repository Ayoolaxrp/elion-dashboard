# Recording Checklist

Use this before recording the competition video.

## Pre recording

- [ ] Confirm production is live
- [ ] Open the site in a clean browser profile if possible
- [ ] Sign out or use an incognito window for public routes
- [ ] Make sure no private dashboards, admin panels, or internal tools are visible
- [ ] Close any tabs that reveal internal tools, logs, or debugging surfaces
- [ ] Decide your demo website in advance
- [ ] Rehearse once without recording

## Demo website

- [ ] Use a real website for the audit
- [ ] Prefer a business that makes the leak obvious
- [ ] Avoid fake or obviously invented businesses
- [ ] Do not claim the audit found something it did not

## Demo path

- [ ] Start on the homepage
- [ ] Show the headline and primary CTA
- [ ] Go to the audit or funnel entry
- [ ] Submit the site
- [ ] Show the results and leaks
- [ ] Move to the recommended automation
- [ ] Move to the demo page
- [ ] Run the demo once
- [ ] Show the automation pipeline completing
- [ ] Show the lead, message, and booking panels
- [ ] Reset the demo if needed
- [ ] End with pricing, booking, or support as the natural close

## Support Assistant

- [ ] Open the support page
- [ ] Open the assistant
- [ ] Ask “How much is the Growth package?”
- [ ] Show the real grounded response
- [ ] Ask one out-of-scope question to show honest refusal
- [ ] Show the handoff to the support form if relevant

## Honesty checks

- [ ] Do not mention fake clients
- [ ] Do not mention fake revenue
- [ ] Do not mention fake ROI
- [ ] Do not mention fake case studies
- [ ] If the demo is illustrative, say so
- [ ] If a flow depends on credentials, say so
- [ ] Do not call ELION a voice agent unless the competition requires one and it actually is one

## Presentation

- [ ] Speak clearly and at a normal pace
- [ ] Keep the video short: 2–3 minutes is enough
- [ ] Do not read a wall of text
- [ ] Let the product do some of the talking
- [ ] End with a clean close

## Recommended close

Say something like:

> “The goal with ELION is simple: find the leak, deploy the system that fixes it, and eventually measure the operational improvement.”

## If something breaks during recording

- [ ] Refresh and try once more
- [ ] If a live flow fails, use the nearest honest fallback state
- [ ] Do not fake a result in post
- [ ] If needed, record the audit and demo separately and edit cleanly

## After recording

- [ ] Watch the full video once before submitting
- [ ] Confirm no internal tools or sensitive information are visible
- [ ] Confirm the demo is not presented as real customer proof
- [ ] Confirm pricing shown matches the site
- [ ] Upload and submit
